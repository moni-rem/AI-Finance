# Publishing the policy and deletion pages

The HTML pages in this folder are ready to publish with GitHub Pages.

1. Push this repository to GitHub.
2. In the repository, open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the default branch and the `/docs` folder, then save.
4. Once GitHub Pages reports the site is live, open and verify:
   - `https://moni-rem.github.io/AI-Finance/privacy-policy.html`
   - `https://moni-rem.github.io/AI-Finance/terms-of-service.html`
   - `https://moni-rem.github.io/AI-Finance/delete-account.html`
5. Enter the Privacy Policy URL in the Play Console privacy-policy field and the Delete Account URL in its account-deletion field.

The Android application ID is `com.financeTrack.finora`. Register that exact package name in Firebase and Google Play. Keep the policy accurate as the app's data handling changes. These draft policies should be reviewed for your business and local legal requirements before release.
